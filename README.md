# Wovu

**The self-hosted, vendor-neutral multiplayer layer for AI coding agents.**

Drop into the same live agent session as your teammates — watch it work, steer it, resume it across tools, and hand it off. On your own infrastructure, under the agents you already use (Claude Code, Cursor, Codex, and any MCP/ACP client).

🚧 **In active development.** This package reserves the name. Follow along at **[wovu.dev](https://wovu.dev)**.

## Coming in V1

- Live, joinable agent sessions (watch + steer, not read-only transcripts)
- Governed shared team memory across everyone's agents
- Cross-tool session resume / rate-limit failover
- Review queue + one-tap approvals + cost governance
- Self-hosted, MIT-licensed, 5-minute on-ramp
